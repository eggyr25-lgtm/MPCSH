MPCSH 1.7 / MPCECC 1.7 (tag shell17)
=====================================

Add these two files to main (Code):

  MPCSH1.7.c   — MarekPC Shell 1.7.0 (~209 KB)
  MPCECC1.7.c  — Extended Capabilities Console 1.7 (~168 KB)

How (GitHub web UI, one shot):
  1. Open https://github.com/eggyr25-lgtm/MPCSH
  2. Add file → Upload files
  3. Drop MPCSH1.7.c and MPCECC1.7.c
  4. Commit message: MPCSH 1.7 + MPCECC 1.7 (shell17)
  5. Commit directly to main

Then tag:
  git tag -a shell17 -m "MPCSH 1.7 multi-window Ctrl+Shift+Tab Krita scaling"
  git push origin shell17
  gh release create shell17 --title "MPCSH 1.7" --notes-file CHANGELOG-1.7.md

What 1.7 includes:
  - Multi-window PixelWindows (wlid)
  - Ctrl+Shift+Tab cycle (WM cannot steal)
  - Default 1440x900, frame cap 1920x1200 (Krita not cut off)
  - CONTAIN aspect fit
